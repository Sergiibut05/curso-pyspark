Así es una lección

Cada fragmento de código sale de un script de practicas/, con lo que imprimió al ejecutarlo.

  • Un script por lección en curso-pyspark/practicas/, para ejecutarlo, cambiarlo y volver a ejecutarlo.
  • Simuladores para lo que no se ve en la salida: cómo se parte una consulta en etapas y qué hace un micro-lote cuando el proceso se cae.
  • El código del repositorio: cada decisión de fusion/job.py, explicada.
  • Ejercicios y preguntas con la solución plegada y comprobada con Spark.

Antes de empezar

Los scripts se ejecutan en el laboratorio del curso, en Docker: un broker de Kafka y una imagen con Python 3.12, Java 17 y PySpark 4.2.1. No hace falta instalar Spark ni Java.

  1. Arranca el laboratorio

    En PowerShell, desde la carpeta laboratorio del curso, donde está su compose.yaml. Todas las órdenes del curso se ejecutan ahí.

    PruébaloPowerShell
    docker compose up -d

  2. Define el atajo

    Una vez por sesión. Ejecuta un script de practicas/ en un contenedor con Spark; la primera vez construye la imagen (unos minutos).

    PruébaloPowerShell
    function spark-py { docker compose run --rm spark python @args }

  3. Ejecuta el primer script

    Y sigue con Qué es Spark y qué hace aquí.

    PruébaloPowerShell
    spark-py 01_hola_spark.py 2>$null
